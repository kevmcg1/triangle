MATHEMATICAL FRAMEWORK VALIDATION
═════════════════════════════════════════════════════════════════════════════

The triangle solver uses Levenberg-Marquardt optimization with these principles:

1. CONSTRAINT ENFORCEMENT
   ─────────────────────────────────────────────────────────────────────────
   Locked Values: Residuals are calculated as (measured - target)²
   Example: If side a is locked to 5.0 in:
     residual = (current_a - 5.0)² → minimized to 0
   Result: Side a remains 5.0 regardless of other changes ✓

2. SIDE LENGTH CALCULATIONS
   ─────────────────────────────────────────────────────────────────────────
   Distance formula: d = √[(x₂-x₁)² + (y₂-y₁)²]
   Applied to vertices: sidesOf() = [dist(B,C), dist(C,A), dist(A,B)]
   Verification: All distance calculations use Euclidean metric ✓

3. ANGLE CALCULATIONS
   ─────────────────────────────────────────────────────────────────────────
   Law of Cosines: A = arccos((b²+c²-a²)/(2bc))
   With clamping: arccos(clamp(value, -1, 1)) prevents numerical error
   Result: Angle always in range [0°, 180°] ✓

4. AREA CALCULATIONS
   ─────────────────────────────────────────────────────────────────────────
   Heron's Formula: Area = √[s(s-a)(s-b)(s-c)] where s = (a+b+c)/2
   Cross Product: Area = (1/2)|P₁×P₂| = (1/2)|x₁y₂ - x₂y₁|
   Both methods implemented, results consistent ✓

5. NUMERICAL STABILITY MECHANISMS
   ─────────────────────────────────────────────────────────────────────────
   ✓ Value clamping in arccos to [-1, 1]
   ✓ Epsilon checks (1e-9) in division-by-zero scenarios
   ✓ Iterative refinement (6 rounds max) for constraint satisfaction
   ✓ Soft weighting to allow small perturbations
   ✓ Line search with lambda adaptation in LM algorithm
